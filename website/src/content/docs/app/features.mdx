The RadioKit Flutter app provides a comprehensive set of features for controlling your Arduino projects.

## Device Management

### BLE Scanning

- Automatic device discovery
- Signal strength display
- Device name and description
- Connection history

### Connection Management

- Multi-transport support (BLE, Serial, WiFi, Cloud)
- Automatic reconnection
- Connection health monitoring
- Password-protected connections

### Authentication

- Password-based device authentication
- Admin access mode
- Secure password storage

## Control Interface

### Dynamic Widget Rendering

- Real-time widget updates (100ms polling)
- Touch-optimized controls
- Haptic feedback
- Spring physics for analog controls

### Widget Types

- **Buttons** — Push and toggle variants
- **Switches** — Slide and rocker variants
- **Sliders** — Linear controls with auto-centering
- **Knobs** — Rotary controls with angle ranges
- **Joysticks** — 2-axis analog controllers
- **LEDs** — RGB indicators with shapes and animations
- **Text** — Read-only text displays
- **Serial Monitor** — Console output in the app
- **Telemetry** — Display-only metrics

### Themes

- **Dragon** — Industrial orange theme
- **Neon** — Cyberpunk cyan theme
- **Minimal** — Clean white theme
- **Custom** — User-defined colors

## Designer

### Visual Editor

- Drag-and-drop widget placement
- Property inspector
- JSON and code view
- Code generation

### Design Management

- Save/load designs
- Export to Arduino code
- Import from JSON

## Developer Tools

### Filesystem Explorer

- Browse device files
- Upload/download files
- Create directories
- Delete/rename files
- Format filesystem

### Firmware Flasher

- Over-the-air updates
- Progress tracking
- Version management

### Debug Tools

- Raw protocol transport
- API request logging
- Console output

## System

### Settings

- Connection preferences
- Display options
- Notification settings

### Logging

- API request log
- Console log
- Export logs

## Remote Access

### HTTP API

- RESTful API on port 7007
- Automated testing support
- Follow mode for remote control

### Cloud Relay

- Ed25519 authentication
- WebSocket transport
- Device discovery
- Remote control
