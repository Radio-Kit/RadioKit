# RadioKit Example Scaffolding

## Overview

This skill provides the canonical patterns for creating new Arduino example projects that demonstrate RadioKit library features. Every example follows a strict structure: a `.cpp` sketch, a `RADIOKIT.h` config, and a `platformio.ini` build file.

## Project Structure

Every example lives in `rk-arduino/examples/<ExampleName>/` and contains exactly three files:

```
rk-arduino/examples/<ExampleName>/
  <ExampleName>.cpp    # Main sketch
  RADIOKIT.h           # Generated config (JSON + widget declarations)
  platformio.ini       # PlatformIO build config
```

## platformio.ini Template

Use this standard configuration for BLE-only examples:

```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200
lib_deps =
    stevemejia/RadioKit@^2.0.0
```

For WiFi/Cloud examples, add build flags:

```ini
build_flags =
    -D RADIOKIT_ENABLE_WIFI
```

For filesystem examples, add:

```ini
board_build.filesystem = littlefs
```

For OTA-capable examples, use a custom partition table:

```ini
board_build.partitions = partitions_ota_4MB.csv
```

## RADIOKIT.h Template

The `RADIOKIT.h` file is generated by the Designer tool but can be hand-written for simple examples. Structure:

```cpp
/*__RADIOKIT_Designer_Config__
{
  "version": 1,
  "config": {
    "name": "ExampleName",
    "description": "Description of the example",
    "theme": "RK_DEFAULT"
  },
  "canvas": {
    "size": [200, 100]
  },
  "widgets": []
}
RADIOKIT_Designer_Config__*/

#pragma once
#include <RadioKitLib.h>

// Widget declarations (global, self-registering)
RK_PushButton btn(20, 60, 20);
RK_LED led(20, 20, 15);

inline void initRadioKit() {
  // Post-construction rk field configuration
  btn.rk.onText = "ON";
  btn.rk.offText = "OFF";
  led.rk.color = RK_GREEN;
}
```

## Sketch Pattern

Every `.cpp` sketch follows this structure:

```cpp
#include "RADIOKIT.h"

void setup() {
  Serial.begin(115200);
  RadioKit.config.name = "DeviceName";
  RadioKit.config.description = "Description";
  RadioKit.config.theme = RK_DEFAULT;

  initRadioKit();
  RadioKit.begin();
  RadioKit.startBLE("DeviceName");  // or startSerial(Serial), startWiFi()
}

void loop() {
  RadioKit.update();  // MUST call every loop iteration

  // Read inputs via rk fields
  if (btn.rk.state) { ... }

  // Update outputs via rk fields
  led.rk.state = true;
}
```

## Key Rules

1. **Always call `RadioKit.update()` in `loop()`** — Required for protocol handling and state sync.
2. **Widgets are self-registering** — Declare globally, no manual registration needed.
3. **Max 16 widgets** per example.
4. **`initRadioKit()` is `inline`** — Defined in RADIOKIT.h, called once in `setup()`.
5. **Config before `begin()`** — Set `RadioKit.config.*` fields before calling `RadioKit.begin()`.
6. **Transport after `begin()`** — Call `startBLE()`, `startSerial()`, or `startWiFi()` after `begin()`.
7. **Password is optional** — Set `RadioKit.config.password = "secret"` only if auth is needed.
8. **Mandatory Flash Erase on Upload** — Upload code with the flash erase option (`pio run -t upload --erase` / `-erase` / `eraseAll: true`) unless previous NVS settings explicitly need to be preserved. Prevents stale device names and old configuration parameters from persisting across flashes.

## Transport Selection

| Transport | Method | Flag Required |
|-----------|--------|---------------|
| BLE | `RadioKit.startBLE("Name")` | None (default) |
| Serial | `RadioKit.startSerial(Serial)` | None |
| WiFi | `RadioKit.startWiFi()` | `-D RADIOKIT_ENABLE_WIFI` |
| Cloud | `RadioKit.startCloud()` | `-D RADIOKIT_ENABLE_WIFI` + WiFi config |

## Widget Quick Reference

| Widget | Constructor | Key rk Fields |
|--------|------------|---------------|
| `RK_PushButton` | `(x, y, height)` | `state`, `onText`, `offText`, `icon` |
| `RK_ToggleButton` | `(x, y, height)` | `state`, `onText`, `offText` |
| `RK_Slider` | `(x, y, height, width)` | `value` (-100..+100), `centering`, `detents` |
| `RK_GasPedal` | `(x, y, height)` | `value`, auto spring-center |
| `RK_Joystick` | `(x, y, height)` | `xvalue`, `yvalue`, `enabled` |
| `RK_Knob` | `(x, y, height)` | `value`, `centering`, `startAngle`, `endAngle` |
| `RK_SteeringWheel` | `(x, y, height)` | `value`, auto spring-center |
| `RK_LED` | `(x, y, height)` | `state`, `color`, `shape`, `ledState`, `timing` |
| `RK_Text` | `(x, y, height, width)` | `content` |
| `RK_SerialMonitor` | `(x, y, height, width)` | `content` (also inherits Print) |
| `RK_SlideSwitch` | `(x, y, height)` | `state`, `onText`, `offText` |
| `RK_RockerSwitch` | `(x, y, height)` | `state` |
| `RK_MultipleButton` | `(x, y, height)` | `value` (index), `items[]`, `itemCount` |
| `RK_MultipleSelect` | `(x, y, height)` | `value` (bitmask), `items[]`, `itemCount` |
| `RK_Telemetry` | `("label")` | `content`, `icon`, `unit` |
